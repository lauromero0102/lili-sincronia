# Cambios futuros

La fuente del proyecto es src/ y public/. No editar dist/ manualmente.
Conservar los textos del catalogo y los 20 minutos de recambio.
Ejecutar npm run build tras cambios.
El usuario solicita sincronizar los cambios de codigo con GitHub: si origin y la autenticacion estan disponibles, ejecutar npm run sync al concluir cada cambio solicitado y verificado. Si falla, informar y conservar los cambios locales; nunca usar force push.
Nunca incluir casos, documentos de pacientes, secretos, archivos de work/ o outputs/ en commits.
